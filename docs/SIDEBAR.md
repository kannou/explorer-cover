# 左サイドビュー（段階6a）

実装日: 2026-09-20

## 操作

- サイドビューはウィンドウ左端に共通で配置する。右側の境界をドラッグすると160〜380 DIPの範囲で幅を変更できる。
- ブックマークまたはドライブをクリックすると、サイドビューを触る直前にフォーカスを当てていたタブでその場所を開く。新規タブは作らず、そのタブの「戻る・進む」履歴に反映する。移動対象のペインをサイドビュー上部に表示し、ツールチップには対象タブの現在地を表示する。
- 「＋ 現在地を登録」で対象タブの現在地をブックマークに追加する。同じ場所の重複登録は行わない。起動時の初期項目はホームとデスクトップ。
- ブックマークを右クリックして名前変更・削除を行う。削除は登録項目だけに適用し、実際のフォルダーは削除しない。到達できない場所は移動先のタブにエラーを表示し、登録は維持する。
- ドライブには名前・ルートパス・総容量・利用可能な空き容量・使用率を表示する。単位はKiB／MiB／GiB／TiB。「更新」で再取得し、10秒ごとにも自動更新する。接続・切断は次回の一覧取得時に反映する。

## 状態と非同期取得

`WorkspaceState.Sidebar`がブックマークと幅を保持する。サイドビューへフォーカスが移っても`ActivePane`と選択中タブは変更しない。移動は`BrowserPane.Navigate`を通し、既存のシェル移動・履歴確定・失敗通知を再利用する。

`DriveMonitor`は一覧取得とドライブごとの問い合わせを分離する。実際の`DriveInfo`アクセスはバックグラウンドで行い、1つの応答が遅くても他のドライブを表示する。同じパスへの問い合わせは完了するまで重ねない。3秒を超えた問い合わせは「応答を待っています…」と表示して待機を継続する。

取り外されたドライブの遅い応答は表示へ戻さない。同じパスに再接続された場合も古い世代の結果は破棄する。画面の終了後に結果を適用せず、監視タイマーを停止する。OS側で実行中の同期問い合わせ自体は強制終了しない。
