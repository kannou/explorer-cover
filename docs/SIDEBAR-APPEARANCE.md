# サイドビューの外観改善（6a-2）

実装日: 2026-09-20

## 表示と操作

- 上にドライブ、下にブックマークを配置する。移動先の文字表示を削除し、ペイン上部の色で操作対象を識別する。クリックした場所は引き続き、直前にフォーカスしていたタブで開く。
- 行と記号ボタンは通常時に枠線と塗りを表示せず、ホバー・押下時に背景色を付ける。フォーカスは細い枠で示し、Enter／Spaceによるボタン操作と右クリックを維持する。
- 見出し右端にドライブ更新の`↻`、ブックマーク追加の`＋`を配置する。記号のクリック領域は28 DIP四方とし、ツールチップとアクセシビリティ用の名前を付ける。
- ドライブは標準アイコン、名前とルート、空き／総容量の1行＋使用率バーで表示する。容量はGiB・小数1桁。意味と使用率の数値はツールチップで確認できる。
- ブックマークは対象のShellアイコン＋表示名＋(フルパス)。初期名はフォルダー名とし、名前変更後は指定した名前を使う。パスは控えめな文字色にし、行末を省略する。ツールチップで全文を確認できる。
- サイドビューの初期幅は280 DIP。ドラッグによる変更は維持する。
- 非アクティブ側のタブバー・移動欄・ステータス欄を灰色にする。アクティブ側の外枠全体は、従来の青系（`#DFEDFC`）にする。選択タブも同色を維持し、一覧の左右にも3 DIPの外枠を設ける。埋め込みExplorerの描画と操作は変更しない。
- 移動欄の「左」「右」を削除する。移動ボタンは右矢印、タブ複製ボタンは2枚の重なった四角のアイコンで表示する。ツールチップとアクセシビリティ用の名前は日本語を維持する。

## ドライブとアイコンの取得

未接続・メディアなしは非表示にする。表示から外しても列挙・問い合わせは継続し、既存の10秒ごとの自動更新または手動更新で利用可能になった項目を表示する。接続イベント監視は追加していない。

`DriveAvailability`で利用可能・未接続・不明を区別する。未接続等のOSエラーは非表示、アクセス拒否や一時的な遅延は容量不明として扱う。既に表示した行は取得失敗だけでは消さない。初回取得が不明の場合は、利用可能と確認するまで表示しない。

Shellアイコンは`SHGetFileInfo`で取得する。COMを初期化した2つのSTA作業スレッドを使用し、UIへは凍結した画像を返す。取得結果を最大256項目までキャッシュし、返されたHICONは画像変換後に`DestroyIcon`で解放する。フォルダーの取得に失敗した場合は汎用のフォルダーアイコンを使う。終了後のUI更新を抑止し、作業スレッドはバックグラウンドとして終了を妨げない。[SHGetFileInfoの仕様](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetfileinfow)
