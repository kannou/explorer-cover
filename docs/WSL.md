# WSLフォルダー対応（6a-3）

実装日: 2026-09-20

## 使い方

パス欄に`\\wsl.localhost\Ubuntu-24.04\home`のようなUNCパスを入力する。`\\wsl$\Ubuntu-24.04\home`も使用できる。タブ複製・履歴・ブックマークは通常のフォルダーと同じ操作で利用する。ディストリビューションのルートでは親へ移動を無効にする。

Linuxの絶対パスだけからのディストリビューション推定、`~`の展開、ディストリビューション一覧UIは今回の範囲外。ブックマーク等の保存は[6bの保存・復元](PERSISTENCE.md)で実装した。

## パスと移動処理

- WSLのディストリビューション配下では大文字・小文字を区別する。`Case`と`case`は履歴・ブックマークで別項目になる。サーバー名とディストリビューション名は大文字・小文字を無視し、`wsl.localhost`と`wsl$`は同じ場所として比較する。Shellが返したパスの表記は保持する。
- ファイル属性の確認、UNCフォルダーの列挙開始確認、`SHParseDisplayName`を、COM初期化済みのSTA作業スレッドで実行する。アクセス拒否は、Shellのモーダルエラーを出す前に通知する。PIDLはバイト列として渡し、`BrowseToIDList`だけをビュー所有元のUIスレッドで実行する。
- 確認中は「移動中…」を表示する。別の場所を再指定すると前の確認を取り消す。15秒でタイムアウトし、失敗時は現在地・履歴・ブックマークを保持する。タイムアウト後・要求変更後・タブ破棄後の結果は画面に反映しない。
- Shellへ渡した後の移動は直列化する。Shell側の移動開始通知が`BrowseToIDList`の復帰後に届く場合も、アプリから要求した履歴移動として扱う。一覧から直接開く場合は通常の新規移動として扱う。
- OSの同期呼び出し自体を強制終了するものではない。作業スレッドは2本、待機キューは32件に制限し、取消済みの待機項目は実行しない。実行中の問い合わせが両方とも長時間停止すると、新しい確認も待機・タイムアウトする。Shell拡張や一覧から直接行うネイティブ操作の待機は、この事前確認のタイムアウト対象外。

## 検証と制限

Releaseビルドは警告・エラーなし。既存の`Verify-Tabs.ps1`も成功し、ローカルのタブ・履歴・選択／スクロール保持・日本語IME・名前変更・ドラッグ移動・ビュー解放を確認した。ログ: `artifacts/tabs-85814139ff6f4bbb88be4c32fca1d697/`。

実機環境はWSL 2、Ubuntu-24.04。専用の`/tmp/explorer-cover-wsl-*`と、Windows側の`artifacts/wsl-*`を使用する。試験用ディレクトリの権限変更は終了時に元へ戻す。

- Coreテスト24件：大小文字、UNC別名、履歴とブックマークの識別、確認中に履歴移動から通常移動へ変更するケースを含む。
- `ExplorerCover.Navigation.Tests`：実際のExplorerHostへ遅延する問い合わせを注入し、他ペインの応答、要求の差し替え、古い結果の破棄、タイムアウト後の再試行、不正入力による取消、タブ破棄後の通知抑止を確認した（4項目成功）。ログ: `artifacts/navigation-tests.txt`。
- `scripts/Verify-Wsl.ps1`：Ubuntu内の閲覧・移動・戻る／進む・親・タブ複製・ブックマーク、大小文字・日本語／空白名、存在しない場所と権限不足、右クリック・コピー・名前変更・QuickLook・Windowsとの双方向ドラッグが成功。ログ・画像: `artifacts/wsl-c142210ebeb347b78172af88fec34230/`。
- WSLからWindowsへの通常ドラッグはコピーになった。この環境ではWindows標準のファイル安全性の確認が表示されたため、作成した検証用テキストへの確認後にコピー結果を検証した。アプリからWindowsのセキュリティ設定は変更しない。
- この環境では、Linuxで作成した相対シンボリックリンクがWindows側でDirectory属性を持たず、フォルダーとして開けなかった。実パスを指定する案内を表示し、現在地を保つ。Linuxのリンク解決を独自に実装していない。
- 自動検証開始時点ではUbuntuとdocker-desktopが起動済みだった。その後のユーザー試用で、停止中のWSLへアクセスすると正常に起動することを確認した（2026-09-20）。遅延・タイムアウトの回復は上記の専用テストで確認した。
